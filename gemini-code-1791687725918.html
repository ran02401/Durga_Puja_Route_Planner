Publish Free to Internet

You can host this entire web application 100% free of cost on static hosting platforms:

Option 1: GitHub Pages (Easiest)

  1. Create a free account on GitHub.
  2. Create a public repository named kolkata-durga-puja-planner.
  3. Upload this exact file saved as index.html.
  4. In repository Settings > Pages, select branch main and click Save!

Option 2: Netlify Drop

  1. Go to Netlify Drop.
  2. Drag and drop the folder containing your index.html file.
  3. Instantly receive a live shareable URL for WhatsApp!
